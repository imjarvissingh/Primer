# Primer — Evaluation

H1 interest-matched theme increases meaningful engagement. H2 may improve unaided mathematics and delayed retention. H3 parents value verified evidence.

Initial 5–10 child pilot is feasibility-focused only, gated by consent, privacy, security and educator review. Record independent baseline, hints, assisted completion, equivalent unseen posttest, delayed retention, adult intervention and parent feedback.

Future comparison: interest-matched vs nonmatched theme, counterbalanced presentation, same pedagogy and equivalent unseen items; appropriately sized study before causal effectiveness claims. No synthetic-data learning claims.
