# Primer — Evaluation

H1 interest-matched theme increases meaningful engagement. H2 may improve unaided mathematics and delayed retention. H3 parents value verified evidence.

Initial 5–10 child pilot is feasibility-focused only, gated by consent, privacy, security and educator review. Record independent baseline, hints, assisted completion, equivalent unseen posttest, delayed retention, adult intervention and parent feedback.

Future comparison: interest-matched vs nonmatched theme, counterbalanced presentation, same pedagogy and equivalent unseen items; appropriately sized study before causal effectiveness claims. No synthetic-data learning claims.

## Observation labels for the demo (Phase 5)
Allowed wording: "Answered independently", "Correct in this short check", "Skipped", "Not reached", "Needs more evidence", "Not yet assessed", "Draft demonstration", "Synthetic demonstration data".

Not supported, and not to be written in the product or the YC application from this demo: mastery or "has learned", improvement or learning gain, retention, effectiveness of either theme, percentage-as-proficiency, diagnosis, predictions, or any statement about real children. The demo has no pilot data and no approved assessment; the only valid claim is that the system can collect and separate independent evidence from assisted practice.

## Demo claims (Phase 6)
Allowed: "this is a working draft of guided practice in two themes, an independent check with no hints, and an adult summary built from server-recorded answers; all data is synthetic." Not allowed: any statement of learning improvement, mastery, engagement, traction, user feedback or educator approval. The summary's wording ("Correct in this short check", "Needs more evidence", "Mastery: not awarded") is deliberately descriptive and must stay so until an educator-approved policy exists. A passing automated test suite is evidence the software behaves as specified, not that it teaches.

## Assisted practice provenance (Phase 8C)

Hints, ten-frame pictures and the warm-up are guided practice. Practice never records evidence, and after a warm-up the mission item keeps its earlier hint count, so nothing counts as independent. No completion or assistance count is accepted from the client. Limitation: practice outcomes are not stored at all, so the demo cannot show how much help a learner used.
